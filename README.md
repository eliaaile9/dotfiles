## Installation

### Prerequisites

Before installing the dotfiles, ensure you have the following tools installed:

- A working linux machine with your distribution of choice

>[!warning]
> On most of my machines i'm using archlinux (btw) and the scripts are meant to be used on a working archlinux machine

- The DE/WM specified in the name of the directory of the dotfiles

### Steps

- Clone this repository
- `cd` in the directory of the dotfiles that you want to install
- Follow the instructions written in `instructions.md` file
- Enjoy :)
